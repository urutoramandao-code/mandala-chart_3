# 単価アップ マンダラチャート(面談用)

SES向けに、PG(〜60万)・SE(〜75万)・PL(〜90万)の3シートで、単価アップに必要な要素を9×9のマンダラチャートで管理するツールです。面談でヒアリングした内容を、リーダーがチャートに入力する使い方を想定しています。

## 使い方

1. `index.html` をブラウザで開きます(ダブルクリックで動きます。インストールやサーバーは不要です)。
2. 「メンバー名」「レイヤー」「ひな形」を選び、「メンバーを追加」を押します。
3. マスを押すと、達成条件が表示されます。「達成にする」を押すと達成済みになり、押した日の日付と番号(#1, #2…)が付きます。達成済みのマスを押すと、「達成を取り消す」が出ます。「戻る」で何もせずに閉じます。
4. 8つの要素は、それぞれ別の色で表示されます。中央の単価のマスは、最初はグレーで、そのシートの65%達成でブロンズ、75%でシルバー、85%でゴールドに変わります。

### スマホでの表示

スマホでも、PCと同じ9×9のマンダラ表示で開きます(画面全体が縮小されて表示されます)。文字が小さいときは、指で拡大(ピンチアウト)してください。チャートの上の「一覧表示にする」ボタンを押すと、要素を縦に並べた、見やすい一覧表示に切り替わります。「マンダラ表示に戻す」で戻ります。

## 主な機能

- 3シート(PG・SE・PL)×8要素×8項目の標準チャート(192項目)
- メンバーごとのチェック、達成日、達成番号、進捗率の一覧
- ひな形(組み込み・基幹アプリ・WEBアプリ)
- 右クリックで達成条件を表示(標準で192項目分を同梱)

## データの保存先(重要)

- メンバーのチェック、チャート内容、達成条件は、**使っているブラウザの中(localStorage)にだけ**保存されます。サーバーには送られません。Gitにも含まれません。
- ブラウザのデータを消すと失われます。ページ下の「データのバックアップ」から、定期的にJSONで保存してください。
- 人ごと・PCごとに別のデータになります。複数人でデータを共有・同期する機能はありません。
- 個人の評価に近い情報を扱うため、このリポジトリには**メンバーのデータを入れないでください**(入るのは、プログラムと標準の内容だけです)。

## チャート内容・達成条件を変更する

画面からの読み込み機能はありません。標準の内容は、`index.html` の中に入っています。

- チャート内容(要素名・項目名): `index.html` の `var D=[` から始まる部分
- 達成条件: `index.html` の `DEFAULT_CRIT` の部分(「# PG」「## 要素名」「項目名|達成条件」の形式)
- `data/mandala_chart.csv` は、上の内容をExcelで確認するための参考資料です。ツールはこのファイルを読み込みません。直しても、画面には反映されません。

文言だけを直す場合は、メンバーのチェックに影響しません。項目の順番や数を変えると、チェックが別の項目に付いたように見えるので、事前にバックアップを取ってください。

```
data/mandala_chart.csv  標準のチャート内容と達成条件
README.md             このファイル
```

## スマホで使う(データはスマホの中だけに保存)

1. このリポジトリをGitHub Pagesで公開します(下の「各自が使えるようにする」)。公開されたURLを、スマホのブラウザで開きます。
2. ホーム画面に追加すると、アプリのように1タップで開けます。
   - iPhone(Safari): 共有ボタン → 「ホーム画面に追加」
   - Android(Chrome): メニュー(︙) → 「ホーム画面に追加」または「アプリをインストール」
3. 入力したデータは、そのスマホのブラウザの中にだけ保存されます。ほかの端末や、PCには出ません。
4. **iPhoneの注意**: Safariで、ホーム画面に追加せずに使い続けると、一定期間(約7日)使わなかった場合に、保存したデータが消されることがあります。必ずホーム画面に追加して使い、ページ下の「データのバックアップ」で、定期的にJSONを保存してください。
5. 一度開くと、電波がなくても開けます(キャッシュされます)。内容の更新があると、次にネットワークが使えるときに自動で最新になります。

```
cd mandala-chart
git init
git add .
git commit -m "マンダラチャートの初版"
git branch -M main
git remote add origin <リポジトリのURL>
git push -u origin main
```

## 各自が使えるようにする

- **配布して開く**: リポジトリをクローン(またはZIPでダウンロード)して、`index.html` を開くだけです。
- **GitHub Pagesで公開する**: リポジトリの Settings → Pages で、ブランチ `main` のルートを指定すると、URLで開けます。ただし、プライベートリポジトリでのPages公開は、契約プランによって使えない場合があります。社外に公開しない運用なら、配布して開く方法が簡単です。
